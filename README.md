# 💳 Desafio em Java — Cartão de Crédito

Projeto desenvolvido em **Java** com o objetivo de praticar conceitos de programação através da criação de uma aplicação relacionada ao uso de um cartão de crédito.

O projeto faz parte da minha trajetória de estudos em programação e foi desenvolvido com foco na aplicação prática de conceitos fundamentais da linguagem Java e de lógica de programação.

---

## 📌 Sobre o projeto

A proposta do projeto é desenvolver uma aplicação capaz de representar operações relacionadas a um **cartão de crédito**, permitindo praticar a criação de classes, atributos, métodos e regras de negócio em Java.

A ideia principal foi transformar um problema simples do cotidiano em uma aplicação, utilizando programação para representar o funcionamento básico de um cartão e suas operações.

---

## 🎯 Objetivos

O desenvolvimento deste projeto teve como principais objetivos:

* Praticar programação em Java;
* Exercitar lógica de programação;
* Trabalhar com classes e objetos;
* Utilizar atributos e métodos;
* Aplicar estruturas condicionais;
* Trabalhar com entrada e processamento de dados;
* Praticar a organização do código;
* Desenvolver uma solução a partir de uma proposta de problema.

## 💳 Funcionamento da aplicação

A aplicação utiliza Java para representar o contexto de um cartão de crédito.

A partir das informações fornecidas pelo usuário, o programa realiza o processamento necessário de acordo com as regras definidas no projeto.

O exercício tem como foco principal a prática da lógica de programação e da estruturação de uma aplicação utilizando os recursos da linguagem Java.

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/Higuz/Desafio-em-java.git
```

### 2. Acesse a pasta do projeto

```bash
cd Desafio-em-java
```

### 3. Abra o projeto

Abra os arquivos do projeto em uma IDE compatível com Java, como:

* IntelliJ IDEA
* Eclipse
* Visual Studio Code

### 4. Execute a aplicação

Localize a classe principal do projeto e execute o método `main`.
